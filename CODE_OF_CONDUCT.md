# Code of Conduct

## Introduction

Welcome, and thank you for your interest in my work. This document is meant to outline the expected behaviors and responsibilities of all contributors and participants
in this project. It aims to create a fair, respectful, and proper environment for any/all contributors, viewers, and participants.

## DO
- Be respectful and considerate towards any and all contributors/people involved in any way with this project.
- Follow the rules and guidelines in this document.
- Report any behavior that violates this code of conduct to Liam, the (as of September, sole developer) of this project (0xLiam0920).
- Create an inclusive and welcoming environment for anyone interested.

## DON'T
- Engage in discriminatory, harassing, or abusive behavior. 
- Engage, create, or add any NSFW, NSFL, or similar content.
- Violate the rules and guidelines set forth in this document.
- Ignore or dismiss violations.
- Create an unwelcoming or hostile environment for others. This project is meant to help people such as educators, students, and anyone interested in the world of astrophysics and science. Keep that in mind.


## What to expect

When contributing, you can expect the following:
- Reports of code of conduct violations will be taken seriously and addressed promptly.
- Contributors and participants are expected to adhere to the guidelines outlined in this document.
- A respectful and inclusive environment will be maintained to the best of the project maintainers' ability.
- Any behavior that violates this code of conduct may result in consequences, including removal from the project or reporting to relevant authorities if necessary.

See `CONTRIBUTING.md` for more details.

## Reporting Violations

If you witness or experience any behavior that violates this code of conduct, please report it to me (Liam) as soon as possible. Include as much detail as possible, such as the nature of the violation, the individuals involved, relevant context or evidence, etc etc. 
All reports will be treated confidentially.

Project maintainers can be contacted via the project's issue tracker or directly through DMs. Cooperation in maintaining a respectful and inclusive environment is greatly appreciated.
